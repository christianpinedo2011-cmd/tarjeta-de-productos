- ## Descripción de la página web

- El proyecto presenta una tarjeta diseñada para mostrar información de varios  productos de manera organizada, atractiva y visualmente agradable.

- La tarjeta de producto cuenta con un diseño moderno y organizado. Incluye elementos visuales, información de los productos  y una estructura que permite presentar su contenido de forma clara.

Se utilizaron HTML para crear la estructura de la página y CSS para darle estilo, colores, distribución y una apariencia atractiva.
